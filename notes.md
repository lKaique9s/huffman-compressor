## Marco 0 — Aquecimento com bits

Já tinha realizado um exercício de manipulação de bits ontem no Exercism, mas agora, mesmo sendo apenas um "aquecimento", a experiência foi diferente.
Dessa vez, precisei pensar de uma maneira mais "funcional" para resolver os exercícios, considerando como cada operação poderia ser utilizada na construção do compressor.

Os exercícios que realizei agora foi:

- **Escrever bits:** receber um int e imprimir sua representação em bits.
- **Ler bytes sem sinal:** realizar a leitura dos bytes ignorando o problema do sinal, evitando que valores acima de 127 fossem interpretados como negativos.
- **Montar um byte:** construir um número a partir de um array contendo bits, utilizando operações bit a bit.

Foi um bom exercício para começar a trabalhar com a manipulação de bits de uma maneira mais próxima de uma aplicação real.
